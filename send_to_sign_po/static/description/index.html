Add a controlled Odoo Sign workflow to Purchase Orders with signature-state tracking and automatic revision management.

Controlled PO Signature Workflow

Send approved Purchase Orders to Odoo Sign, track the signing lifecycle, and automatically reopen the signing process when commercial content changes.

Send to Sign Action

Adds a dedicated action on eligible confirmed/approved Purchase Orders to generate the PO document and start the signature process.

Signature State

Track whether the PO is awaiting signatures, completed, rejected or otherwise moving through the configured signature workflow.

Revision Control

Maintain R-number revisions for Purchase Orders so updated commercial documents can be distinguished from previously signed versions.

Change Detection

When relevant PO data changes after signing, the module resets the signature readiness and increments the revision so the updated document can be signed again.

PO PDF Revision

The Purchase Order report is extended so the document carries its revision information.

Scheduled Status Updates

Included scheduled processing helps synchronize signature progress back to the Purchase Order.
